## [1.0.0] - 2026-07-26

### Added

- Tkinter desktop interface
- Video-only stream extraction with FFmpeg
- Audio-only MP3 export
- Local transcription with faster-whisper
- Automatic and explicit language selection
- CPU, CUDA, and automatic device modes
- Clean UTF-8 transcript generation
- Optional timestamped transcript
- Background worker thread
- Progress reporting and activity logging
- Cancellation support
- Windows installer and launcher
- Linux and macOS installer and launcher
- Windows diagnostic script
- Transcript-cleanup unit tests
