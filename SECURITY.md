# Security Policy

## Supported versions

Security fixes are applied to the latest published version and the current
`main` branch.

## Reporting a vulnerability

Do not report security vulnerabilities in a public GitHub issue.

Use GitHub's private vulnerability-reporting option from the repository's
Security tab when it is available. If private reporting is not enabled, contact
the maintainer through the contact information published on the maintainer's
GitHub profile.

Include:

- A clear description of the issue
- Steps to reproduce it
- The affected operating system and version
- The affected application version or commit
- The potential impact
- Any suggested mitigation

Do not include private videos, audio recordings, transcripts, credentials, or
personal data unless a secure exchange method has been agreed upon.
